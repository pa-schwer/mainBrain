Everything a session could do is done: the repos are generated, their
dependencies installed, their checks green, their first commit made on
`main`, the skills installed, the security rules and CI in place. This
file is the rest: the steps that need a human, because a session has no
way to do them (a personal GitHub account, a billing account, a console
that wants a browser session, a secret that must never pass through a
chat).

Each step says where to go, what to do, and the **proof**: the check that
turns green when it is done. Do them in order; later steps depend on
earlier ones. Tick the box when the proof is green, not before.

A session that needs one of these steps names it by number and waits. It
never invents a value and never skips the proof.

One step has an automatic path: G1, creating the repositories, is done by
mainBrain's "Create repositories" workflow when that workflow has been
armed once for `{{OWNER}}` (`mainBrain/docs/repo-creation.md`). Then the
session creates and pushes without a click, and G1 is a line in a log.
