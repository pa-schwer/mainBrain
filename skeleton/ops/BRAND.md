# {{TITLE}}: brand memory

PLACEHOLDER. The founder supplies this file; a session never invents it.

Every session that writes something a user will read reads this file in
full first: a screen, an email, a notification, a generated answer, a
result label, the text a scoring rule produces. Sessions in the other
repos read it here, by path, as they read `docs/workflow.md`; there is
one copy, in this repo.

What it holds, once supplied, in whatever order the founder wrote it:

- who the product speaks to, and how it speaks to each of them;
- the voice: what it is, what it is not;
- the key messages, in {{COPY_LANGUAGE}};
- the writing rules for {{COPY_LANGUAGE}}, and the words that are banned;
- the trust, legal or safety rules any text must obey;
- reference microcopy;
- the checklist a pull request that changes visible text passes before
  merge.

Until it exists, copy follows `docs/product.md` and the stop-slop
directive, and a pull request that adds visible text says in its body
that this file was still a placeholder.
