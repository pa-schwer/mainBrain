# Core Memory

Summaries and pointers. Detail lives in `topics/`. This repo is public;
nothing here names a person, an account, a project or a secret.

## What this repo is

A generator (skeleton + answers file → workspace) and a skills library,
with a return path (`upstream.py`) so projects feed their structural
improvements back. Everything a session can do, `spawn.sh` does; the
rest is a generated `HANDOFF.md` with a proof per step.
→ CLAUDE.md, docs/upstream.md

## Environment

Web sessions: no `gh`, no `firebase`, no `wrangler`. The Claude GitHub
App cannot create repositories, on a personal account or an organization,
so `HANDOFF.md` G1 is a human step. The container is ephemeral; git is
the only persistence.
→ topics/environment.md

## Spawns

One line per spawn, kinds and needs only.
→ topics/spawns.md

## Library

One source per domain. Candidates already weighed (web-design-guidelines,
playwright-cli, taste-skill, awesome-design-md) and the container config
playwright-cli needs.
→ topics/library.md
